# controle-niveis-agua

# Descrição

Este projeto é um sistema simples de monitoramento de níveis de água de um reservatório, desenvolvido em Python para execução no terminal.

O objetivo do programa é exibir mensagens coloridas indicando a situação atual do reservatório, facilitando a visualização dos níveis de risco através da biblioteca Colorama.

# Funcionalidades

Exibe cinco níveis de água do reservatório;
Utiliza cores diferentes para cada situação;
Organiza os níveis em uma lista;
Usa uma função para definir as cores das mensagens;
Restaura automaticamente o estilo padrão do terminal.

# Níveis do Reservatório

Nível	Situação - Cor

1	Muito baixo (crítico): Vermelho

2	Baixo: Amarelo

3	Médio: Verde

4	Alto: Ciano

5	Muito alto (alerta): Azul

# Tecnologias Utilizadas
Python 3
Biblioteca
Colorama
